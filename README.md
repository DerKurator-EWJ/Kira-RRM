# Kira RRM – historisches Entwicklungsarchiv

Dieses Repository archiviert mehrere **getrennte** RRM-Entwicklungszweige.
`modules/` enthaelt den jeweils zuletzt importierten Stand jedes Zweigs;
aeltere Staende sind ueber die zugehoerigen Git-Tags abrufbar.

**Hinweis:** Die Reihenfolge zwischen verschiedenen Zweigen folgt einer
Dateiliste, nicht verifizierten historischen Erstellungszeitpunkten.
Lauffaehigkeit und Integration der Module sind nicht allein durch den Import belegt.
